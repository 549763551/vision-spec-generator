## 模型边界

光学实验室会根据型号切换底板长宽比例、支架形态（标准立柱、四立柱大视野、便携双支柱）和设备规格卡片。3D 模型是结构关系示意：不代表真实比例、导轨行程、负载、刚度、定位精度，也不模拟电气控制器内部电路。镜头视场、工作距离和光源照明计算仍沿用项目已有模型。

实际选型、采购和装配前，应向厂商索取正式图纸与规格书，确认工作台面尺寸、各轴行程、重复定位精度、支架负载、夹持范围、控制器输出能力及相机接口定义。
