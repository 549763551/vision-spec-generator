## 模型边界

厂商资料中明确的机架形态用于选择三维示意：标准立柱、大视野四立柱和便携双支柱。三维中的台面、型材截面、滑块和连接方式属于结构关系表达，不代表实际比例、导轨行程、支架负载、刚度或重复定位精度；镜头视场、工作距离和光源照明计算仍沿用项目既有模型。

采购与机械设计前，应向厂商索取正式图纸和规格书，确认工作台面尺寸、各轴行程、重复定位精度、支架负载、夹持范围、控制器输出能力及相机接口定义。

## 数据维护

厂商设备资料唯一真源：`web/bench-data.js`。本地动态页由 `web/lab.html` 读取该文件；静态页面通过 `python scripts/build_docs.py` 生成 `docs/lab.html` 并同步复制 `docs/bench-data.js`。不要直接修改 `docs/lab.html` 或 `docs/bench-data.js`。
