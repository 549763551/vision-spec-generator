关于这个在线版本

GitHub Pages 只能托管静态文件。这里的三维实验室把选型计算内嵌到了 lab-data.js，与本地 core/scene.py::build_lab() 的返回值逐字段等价， 因此换灯型、改视野、改工作距离的行为和本地版一致。

完整的方案工作台（任务选型、图纸解析、方案书生成、3D 拆解）依赖 Python 后端， 需要克隆仓库后在本机启动： 

# 克隆并启动本地服务，然后访问 http://127.0.0.1:8848/
git clone https://github.com/Qsianuo/vision-spec-generator.git
cd vision-spec-generator
python demo_server.py 8848
