# OPT 标准光源品类与实验室模型对照

用途：判断 `web/lab.html` 里的光源外形、安装位、发光方向是否与 OPT 实物一致，并说明哪些品类**故意不建模**。

来源：
- OPT 官网「标准光源」<https://www.optmv.com/p_bzgy/index.html>（2026-11 抓取，页面为动态渲染，品类名以官网分类与系列页为准）
- 课程讲义《机器视觉光源选型》中面光 / 背光 / 圆顶 / 隧道 / 线光的定义
- 本仓库 `core/scene.py` 的 `FORM_SHAPE`、`web/lab.html` 的 `buildLightModel()`

> 说明：系列代号仅用于对照，不保证覆盖官网全部在售型号；具体参数以官网为准。

## 1. 已建模的 8 种形态

| 品类 | 实验室 series | OPT 典型系列 | 实物形态与发光方式 | 实验室实现要点 |
|---|---|---|---|---|
| 环形光 | `RS` | 环形系列 | 圆环灯珠排一圈，灯珠相对水平面内倾，α=90° 垂直向下，α 越小越掠射 | 环体 + 内倾灯珠 + 光幕柱；光斑半径 `\| r − h·cot α \|` |
| 条形光 | `2BS` | 条形系列 | 两根（或四根）长条灯管，由横担分两路下挂，各自可调角度 | 双灯管 + 横担 + 独立夹持，对应 `dual` 安装 |
| 面光源（背光） | `HFS` | FL / FLA / FLC / FLP | **背光位**：平面发光、发光面朝上，工件放在发光面上方，相机俯视取剪影；FLC / FLA-K 为中孔型，可改作前光 | 箱体坐台面（y=0），发光面朝上，工件整体抬到发光面上方；前置照明用侧栏开关表达，不动标准背光位 |
| 平行面光源 | `PHFS` | 平行光系列 | 面光加平行膜（微结构细齿），把发散光折成近平行光，减少边缘阴影 | 背光箱顶面加一排细齿膜；覆盖率按发光面投影计 |
| 同轴光 | `CO` | 同轴系列 | 沿相机光轴垂直向下，经 45° 半反镜折转，适合高反光平面 | 半反镜方块 + 光轴同轴发光体，安装高度固定在镜头前 |
| 圆顶光 / 无影光 | `DS` | 穹顶 / 无影系列 | 倒扣碗罩住工件，**顶部开镜头孔**让相机往下看，灯珠沿底部内圈打向腔顶，靠腔体漫反射形成无影照明 | 半球壳开顶部孔（`SphereGeometry` 用 `phiStart/phiLength` 留孔）+ 内壁漫反射 + 底圈灯珠；悬臂改在裙边高度侧向夹持，不越顶 |
| 隧道光 / 拱形光 | `TUG` | LVS / LIU | **长条凹槽灯**：深色铝外壳 + 白色漫反射拱形内衬 + 底部灯珠向上打，两端端盖，侧面散热风扇，**拱顶留一条纵向开口**让镜头看进去，可做得很长配线阵 | 左右两片半拱拼出真开口（按缝宽反算缺口半角）+ 压条 + 端盖 + 侧风扇 + 安装脚；长度至少 60 mm 才像长条凹槽 |
| 线光源 | `LPG` | LPG / LSA | **长条厚灯箱**：底部一条窄缝出光，顶部一排散热鳍片与风扇，端部走线接头，配线阵相机逐行扫描 | 厚灯箱 + 顶部 9 片鳍片 + 2 个风扇 + 底部窄缝发光面 + 端部接头；光幕为薄片（slab） |

这 8 种的共同点：**灯体水平刚性安装，改的是灯珠内倾角**；全程没有斜拉细杆或吊线。安装方式按灯型分开：背光坐台面、圆顶侧向夹持、其余由悬臂与夹座固定。

## 2. 未建模的品类及原因

| 品类 | 为什么不在 3D 实验室里建模 | 替代表达 |
|---|---|---|
| 点光源 | 体积小、常配光纤或透镜使用，形态与环形/同轴高度重叠，单独建模对选型判断帮助不大 | 用同轴/环形近似 |
| 光纤光源 | 本质是「光源主机 + 光纤束 + 出光头」，出光头形态可归入环形/条形/点光 | 不建模 |
| 程控图案光源 | 核心价值是图案可编程（条纹、棋盘、圆点），属于结构光/相位测量范畴，不是静态外形问题 | 不建模 |
| 直射圆形光 | 与面光/背光形态接近，只是出光面为圆形 | 用面光近似 |
| 结构光投影模块 | 与 3D 相机配套，输出的是图案而非均匀照明 | 不建模 |
| 分区照明光源 | 价值在「多通道独立调光」，外形与条形/面光相同，差异在控制器 | 用亮度/色温控制近似 |
| 高显色指数光源 | 差异在光谱（CRI），外形与标准白光相同 | 用色片/色温表达 |
| 红外 / 紫外光源 | 差异在波长，肉眼不可见；3D 里只能用示意色表达 | 用 `?tint=ir` 等色片示意，页面注明「非定量光谱」 |

判断原则：**实验室只建「形态差异会改变打光判断」的品类**。波长、通道数、图案这些差异不改变 3D 几何，建模反而会误导学生以为换个灯壳就能得到红外效果。

## 3. 与课程讲义的对应

| 讲义概念 | 实验室落点 |
|---|---|
| 面光 / 背光 | `HFS`（背光位、发光面朝上、剪影） |
| 平行面光 | `PHFS`（平行膜细齿） |
| 圆顶光 / 无影光 | `DS`（顶部镜头孔 + 腔体漫反射） |
| 隧道光 / 拱形光 | `TUG`（长条凹槽 + 拱顶纵向开口） |
| 线光源（配线阵） | `LPG`（厚灯箱 + 底部窄缝） |
| 环形光 / 条形光 | `RS` / `2BS` |
| 同轴光 | `CO` |

课程里强调的两个易错点，已经在模型里纠正：

1. **面光不是「悬在工件上方往下打」**——标准用法是背光位，发光面朝上；只有中孔型（FLC / FLA-K）才做前光。
2. **线光不是「细圆管斜吊」**——是长条厚灯箱，配线阵相机；隧道光也不是半透明玻璃筒，而是带端盖、风扇、顶部开口的拱形铝壳。

## 4. 覆盖率的计算口径

实验室的照度网格是为**反射式直射光**写的（只统计朝下的发光体），因此：

- 环形 / 条形 / 同轴 / 线光 / 隧道：按直射光落在 FOV 网格上的比例与均匀度计算；
- **背光（HFS / PHFS）**：按发光面相对 FOV 的投影覆盖计算，发光面比视野大即 100%；
- **圆顶光（DS）**：工件被罩在腔内，按 100% 覆盖计；
- 背光与圆顶的均匀度取决于扩散板与腔体，**不做定量仿真**，HUD 显示「—」，避免给出编造的数值。

页面底部保留「不做定量照度仿真」的边界说明，与 `README.md` 一致。
